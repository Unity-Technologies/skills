# LevelPlay documentation topic map

Each link below opens the Markdown version of a LevelPlay documentation page. Fetch only the page that covers your current step.

- [Unity Package integration](https://docs.unity.com/en-us/grow/levelplay/sdk/unity/package-integration.md): installation, **Network Manager**, SKAdNetwork, and `AD_ID`. Skip its App Transport Security section, which turns off transport security for the whole app; use `ios-setup.md` in this folder instead.
- [Add an app](https://docs.unity.com/en-us/grow/levelplay/platform/get-started/add-app.md) and [Manage ad units](https://docs.unity.com/en-us/grow/levelplay/platform/get-started/ad-units.md): create the app and ad units in the LevelPlay dashboard.
- [Google AdMob integration](https://docs.unity.com/en-us/grow/levelplay/sdk/unity/networks/guides/google-admob.md): AdMob app ID and adapter setup.
- [Regulation advanced settings](https://docs.unity.com/en-us/grow/levelplay/sdk/unity/regulation-advanced-settings.md): the GDPR consent, CCPA, and COPPA settings for each SDK version.
- [Rewarded ads](https://docs.unity.com/en-us/grow/levelplay/sdk/unity/rewarded-ad-integration-package.md), [Interstitial ads](https://docs.unity.com/en-us/grow/levelplay/sdk/unity/interstitial-integration.md), and [Banner ads](https://docs.unity.com/en-us/grow/levelplay/sdk/unity/banner-integration.md): the ad unit API for each format.
- [Impression-level revenue integration](https://docs.unity.com/en-us/grow/levelplay/sdk/unity/impression-level-revenue-integration.md): the `OnAdImpressionDataReady` event.
- [Integration test suite](https://docs.unity.com/en-us/grow/levelplay/sdk/unity/integration-test-suite.md): turn on and launch the Test Suite.
- [Maven Central migration guide](https://docs.unity.com/en-us/grow/levelplay/sdk/unity/maven-central-migration-guide.md): upgrade to 9.0.0 or later, and fix `is.com` dependency failures.
